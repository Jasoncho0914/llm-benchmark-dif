# Differential Item Functioning as an Item-Level Diagnostic for LLM Benchmarks

This repository contains the reproducibility materials for the paper:

**Differential Item Functioning as an Item-Level Diagnostic for LLM Benchmarks**

The analysis uses item-level response data from the Open LLM Leaderboard v2 across six benchmarks.

**Status:** Reproducibility code is being prepared and will be uploaded to this repository.
